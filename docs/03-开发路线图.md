# 03 · 开发路线图

> 时间基准：课程汇报在第九/十周，有效开发约 1~2 周。里程碑按"验收标准"推进，不按日期硬赶——但 M1 必须最早完成，它验证整条技术链路。

## 里程碑总览

| 里程碑 | 内容 | 验收标准 | 预估 |
|---|---|---|---|
| **M0 仓库与文档** | git、文档系统、代码骨架、数据契约 | `uvicorn server:app` 起 /health 通；pytest 绿 | ✅ 已完成 |
| **M1 最小闭环** | ①抽取：一条 JD → ExtractedRequirements | pytest 覆盖①；缓存生效（同输入二次调用不耗 token） | 1 天 |
| **M2 数据资产** | 50~100 条真实 JD（附链接）+ curriculum.json + opportunities.json；②归并 + 频次表 | /api/analyze 返回某岗位方向的核心/加分技能表 | 2~3 天 |
| **M3 映射与路线图** | ③映射 ④规划 + SQLite 档案存取 | 输入画像 → 多学期 Roadmap JSON，重启不丢 | 2 天 |
| **M4 对话与多 Agent** | ⑤对话 Agent：SSE 流式 + 工具调用 + 重规划；小规模多 Agent 链（分工+1轮review+汇总） | 演示脚本两个场景跑通：完整任务 / 就业→考研切换 | 2 天 |
| **M5 前端与演示** | 前端决策与实现；缓存回放 + 录播；2~3 轮组内测试留痕；彩排 | 全流程彩排 ≤ 5 分钟，录播文件在手 | 2~3 天 |

## M5 前端决策点（届时二选一）

- A：手写简版网页（HTML+JS fetch/EventSource）——零新依赖，工作量 1~2 天。
- B：PydanticAI 官方 Vercel AI / AG-UI 适配器 + 现成聊天组件——体验好但引入 React/npm 生态，需有人会。
- 决策规则：组里有人熟 npm 选 B，否则 A。**该决策写 ADR-0003。**

## 任务分解与角色建议（5 人）

| 角色 | 负责 | 主要落点 |
|---|---|---|
| 数据（2 人） | JD 收集与清洗、培养方案/机会清单 JSON | data/ |
| 流水线（1 人） | ①②③④ + 缓存 | pipeline.py, store.py |
| Agent 与服务（1 人） | ⑤、FastAPI 路由、SSE | agent.py, server.py |
| 测试与文档（1 人） | pytest、测试轮留痕、演示脚本与录播 | tests/, docs/04 |

角色是责任边界不是墙：契约（schemas.py）改动全员周知。

## 风险与保底

| 风险 | 应对 |
|---|---|
| PydanticAI v2 太新、教程断层 | 只认 pydantic.dev 官方 v2 文档；锁版本；坑记入 05 文档"常见坑" |
| API 限流/断网（演示） | 全链路缓存回放 + 录播视频双保险 |
| 时间不够 | 砍序：M4 的多 Agent 链 → 前端换最简版 → 汇报侧重职业思考（占分最高） |
| LLM 输出偶发不合 schema | PAI 校验自动重试兜底；仍失败则该输入记入测试轮问题清单 |
