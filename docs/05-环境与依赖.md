# 05 · 环境与依赖

## 运行环境

- Windows + Git Bash（`D:\Project\Program_tools\Git`）
- Python：统一用 Anaconda 发行版建虚拟环境：`D:\Professional_soft\anaconda3\python.exe`（3.11+）；组员各自机器没有 Anaconda 的，任何 Python ≥3.11 亦可
- 编辑器不限（VS Code 推荐，装 Python + Ruff 扩展）

## 首次搭建（Git Bash）

```bash
cd /d/Project/职规Agent
/d/Professional_soft/anaconda3/python.exe -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt
# 首次装完后立刻锁版本并提交：
pip freeze > requirements.lock.txt
cp .env.example .env   # 填 API key（.env 永不提交）
uvicorn server:app --reload
```

日常开发只需：`source .venv/Scripts/activate` → `uvicorn server:app --reload`。

## API Key（.env）

| 变量 | 说明 |
|---|---|
| DEEPSEEK_API_KEY | DeepSeek 开放平台申请，充值即用，开发期成本极低 |
| ZAI_API_KEY | 智谱开放平台（备选，有免费 GLM-4-Flash 档，适合开发调试） |
| CAREER_MODEL | 模型串，如 `deepseek:deepseek-chat`；切换厂商只改这一行 + 对应 key |

模型纪律：主链路只用非推理档（deepseek-chat / glm-4-flash 级）；演示用标准档；**绝不在主链路用推理模型**（思考数十秒，演示灾难）。
