# 演示流程清单（现场约 5 分钟）

1. 预热（演示前一次性）：`.venv/Scripts/python.exe scripts/warm_cache.py`——预热覆盖 ①全量抽取、③④就业+考研两版、⑤第 5 步的两条对话消息；看输出"二跑全缓存回放秒级"即断网回放就绪
2. 启动：`.venv/Scripts/python.exe -m uvicorn server:app`，开 `http://127.0.0.1:8000/`（前端由服务直接挂出）
3. 表单：小陈·大二上·后端开发工程师·就业·每周 15h·已有基础 Python/MySQL，提交（**提交前看一眼"补充说明"框：保持为空，或保留"希望大三能进大厂实习"也行——两种都已在缓存里，别改成其他文字，改了就变联网真调用**）
4. 分析页：岗位技能频次表（①②）→ 课程/竞赛/项目映射（③）→ 八学期时间轴（④）依次呈现（讲解口径：语料以 Java 系岗位为主，MySQL/Java 频次居首属真实市场结构，正好印证"数据是真实 JD 而非编造"）
5. 对话：右下角气泡打开实时对话，按预热冻结的原文问"现在这样安排合理吗？"，再问"我想转考研，不找工作了"（两条消息已被预热脚本写入缓存，断网也回放；改问其他问题则需联网真调用）
6. 改考研重排：表单路线改成"考研"重新提交，对比时间轴——大三下起数学/408 备考、实习与秋招让位、大四上 12 月初试冲刺
7. 压轴：断网重跑第 3~6 步，全部命中 SQLite 缓存秒级回放（LLM 缓存即离线演示的根基）
